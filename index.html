nijimi · 滲み · 编辑器

nijimi（滲み），字面是「墨在纸上洇开」。轻量级 diorama 渲染引擎的四个生产工具，标定值回写引擎本体（src/*）。 人物 = 单模型；姿势/动画 = 角色动作库；场景 = 纯环境；集成 = 内容包 × 角色融合。 消费方（游戏侧）直接 import 同一套引擎，读到的就是这里看到的东西。

01 · CHARACTER

人物编辑器

单人模型渲染调试：骨架 / 关节点 / 材质四模式（贴图·Unlit·法线·线框）/ 灯光曝光 Bloom。夜兰的眼睛、朝向、PMX 修正都在这里标定。

/editors/character.html
02 · POSE

姿势实验台

动作库生产工具：26 个语义槽位（前俯后仰 / 左右转 / 左右侧倾）摆姿势 → 存本地库 → 排成关键帧动作串播放。呼吸/轻摆叠加层让静止姿势活起来。

/editors/pose.html
03 · SCENE

场景编辑器

纯环境调试（无人物）：房间 + 工业簇 + 粒子，灯光四路 / Bloom / 曝光 / NPR 手法开关，主工程同款视窗 rig。createStage(container, { pack, withCharacter: false })。

/editors/scene.html
04 · INTEGRATED

集成编辑器

完整场景 + 人物的融合调试：人物朝向 / 站位微调 + 全套灯光后期滑杆。内容包 × 角色 × 后期全链调试，标定值回写 stage.ts / character.ts。
